📘 Introducción
Por qué y cómo usar Excel con el sistema InventarioMovil
🎯 ¿Por qué usar Excel con el sistema?

InventarioMovil está diseñado para leer directamente tus archivos Excel existentes, sin necesidad de migrar datos ni aprender una nueva interfaz de entrada. Simplemente prepara tu archivo con el formato correcto y el sistema hace el resto.

  • Importa cientos o miles de equipos en segundos
  • Compatible con archivos Excel que ya usas en tu empresa
  • Detecta automáticamente el tipo de equipo por el nombre de la hoja
  • No necesitas configurar nada — el sistema aprende de tu estructura
  • Puedes exportar la base actualizada y usarla como nueva plantilla
📄 Formatos de archivo soportados
.xlsx .xls .xlsm .csv .ods

💡 El formato recomendado es .xlsx (Excel moderno). Los archivos .csv solo tienen una hoja, por lo que se importan como una única categoría.

🔄 Importación automática: El sistema detecta y lista todas las hojas de tu archivo automáticamente. Puedes elegir cuáles importar antes de confirmar.

🗂️ Estructura del Archivo Excel
Cómo nombrar tus hojas para que el sistema las reconozca
📌 Regla clave: El sistema detecta el tipo de equipo por el nombre de la hoja, no por el contenido. Nombra tus hojas correctamente y la importación será automática.
Nombre de la Hoja Se importa como Notas
CORPORATIVOS TELEFONOS CELULARES 📱 Teléfonos Corporativos Busca columnas IMEI 1, IMEI 2, CODIGO, MARCA, MODELO
PC LAPTOPS COMPUTADORES LAPTOPS 💻 Computadoras / Laptops Busca columnas SERIE, TIPO, MARCA, MODELO
ELECTRODOMESTICOS 🔌 Electrodomésticos Busca columnas ARTICULO, MARCA, SERIE, OFICINA
MOBILIARIO MUEBLES 🪑 Mobiliario Se trata como electrodomésticos con subtipo genérico
Cualquier otro nombre 📦 Categoría genérica Se importa con categoría igual al nombre de la hoja
TABLA DINAMICA RESUMEN 🚫 SE IGNORAN Estas hojas son saltadas automáticamente
⚠️ Mayúsculas/Minúsculas: El sistema reconoce los nombres de hojas en mayúsculas o minúsculas indistintamente. CORPORATIVOS = Corporativos = corporativos.

🔵🟢🔴 Estados Reconocidos por el Sistema
Cómo el sistema determina el estado de cada equipo automáticamente
🤖 Normalización automática: El sistema analiza la columna ESTADO y el nombre del colaborador para determinar el estado real de cada equipo. No necesitas usar exactamente el mismo texto.
✅
Asignado
Se asigna cuando hay nombre + DNI del colaborador en la fila.
También cuando el nombre de la persona es válido y no hay indicador de stock.
ESTADO puede decir: ACTIVO, ASIGNADO, o estar vacío.
📦
Stock
Se asigna si ESTADO contiene alguna de estas palabras:
STOCK · ALMACEN · DISPONIBLE · LIBRE
También cuando no hay nombre de responsable ni estado definido.
⛔
Broken / Baja
Se asigna si ESTADO contiene alguna de estas palabras:
BAJA · BROKEN · DAÑO · AVERIA · TALLER · REPARACION
❓
Stock (por defecto)
Si no hay datos de responsable ni estado claro, el sistema asigna Stock como estado por defecto para evitar datos incorrectos.
📋 Valores aceptados en la columna ESTADO
Texto en Excel Estado resultante Color
ACTIVO, ASIGNADO, (vacío con nombre) Asignado Verde
STOCK, ALMACEN, DISPONIBLE, LIBRE Stock Azul
BAJA, BROKEN, DAÑO, AVERIA, TALLER, REPARACION Broken / Baja Rojo

🚀 Pasos para Importar tu Archivo
Guía paso a paso del proceso de importación
1
📂 Ir al módulo "Cargar Archivo de Inventario"
Desde el menú lateral, selecciona la opción "Cargar Excel" o "Cargar Archivo de Inventario".
2
🖱️ Arrastra tu archivo a la zona de carga
Arrastra tu archivo .xlsx directamente a la zona marcada, o haz clic en "Seleccionar archivo" para buscarlo en tu computadora.
3
📋 El sistema lista todas las hojas detectadas
Verás un listado con todas las hojas encontradas en el archivo, con el tipo de equipo que el sistema asignará a cada una.
4
☑️ Marca las hojas que deseas importar
Por defecto todas las hojas válidas vienen marcadas. Desmarca las que no quieras importar (ej: hojas de respaldo o pruebas).
5
✅ Haz clic en "Importar hojas seleccionadas"
Confirma la importación. El sistema procesará cada hoja y normalizará los datos automáticamente.
6
📊 El sistema va al Dashboard con todos los datos
Serás redirigido automáticamente al Panel General donde verás los conteos, gráficos y el inventario completo actualizado.
7
💾 Los datos se guardan automáticamente en el servidor
No necesitas hacer nada más. Los datos quedan persistidos y disponibles desde cualquier dispositivo con acceso al sistema.
⚠️ Importante: Importar un nuevo archivo reemplaza toda la base anterior. Asegúrate de exportar primero si deseas conservar asignaciones y cambios manuales previos.

🛠️ Errores Comunes y Soluciones
Problemas frecuentes al importar y cómo resolverlos
Error / Síntoma Causa probable Solución
❌ "El archivo está vacío" Las hojas no tienen datos o están en blanco Verifica que la fila 1 tenga cabeceras y la fila 2 en adelante tenga datos reales
🔵 Equipos aparecen como "Stock" cuando deberían estar "Asignados" Falta la columna APELLIDOS Y NOMBRES o está vacía Agrega la columna con el nombre completo del colaborador en cada fila
❓ No reconoce el tipo de hoja El nombre de la hoja es muy distinto al esperado Renombra la hoja a CORPORATIVOS, PC LAPTOPS o ELECTRODOMESTICOS
📵 IMEIs no aparecen en el detalle del teléfono La columna tiene un nombre diferente Usa exactamente IMEI 1 e IMEI 2 como nombres de columna (con espacio)
🏷️ Teléfonos sin código identificador Falta la columna CODIGO Agrega la columna CODIGO con valores únicos, ej: CBZ-TLF-001
📅 "Fecha inválida" al importar Formato de fecha incorrecto en la columna Usar formato DD/MM/AAAA o AAAA-MM-DD
✅ Consejo: Si el sistema importa pero con datos incorrectos, abre el archivo en Excel, corrige los nombres de columnas usando los exactos de este curso, guarda y vuelve a importar.

⭐ Consejos Pro
Mejores prácticas para sacarle el máximo al sistema
📤
Exporta antes de importar: Usa el botón "Exportar Excel" del sistema para descargar la base actualizada con asignaciones y cambios manuales, y úsala como punto de partida para tu nuevo archivo.
🔄
Importar reemplaza todo: Cuando importas un nuevo archivo, el sistema reemplaza toda la base anterior. No mezcla datos. Esto garantiza que siempre tengas una base limpia y sin duplicados.
🤖
Marcas nuevas = sin configuración: El sistema reconoce marcas nuevas automáticamente. No necesitas configurar ningún catálogo — simplemente escríbelas en la columna MARCA.
☑️
Hojas opcionales: Puedes tener hojas adicionales en tu archivo (respaldos, cálculos, etc.) que no quieras importar — simplemente desmárcalas en el selector de hojas antes de confirmar.
🏷️
CODIGO es el identificador de teléfonos: Para teléfonos corporativos, el CODIGO es el identificador principal para el QR. Si no tienes código propio, el sistema usará el IMEI 1 automáticamente.
📏
Mantén la fila 1 como cabecera: La primera fila de cada hoja debe contener los nombres de las columnas (CODIGO, MARCA, MODELO...). Los datos empiezan desde la fila 2. No uses filas de título fusionadas sobre las cabeceras.
📅
Fechas consistentes: Usa siempre el mismo formato de fecha en todo el archivo: DD/MM/AAAA (ej: 15/03/2024) o AAAA-MM-DD (ej: 2024-03-15). Mezclar formatos puede causar errores de importación.
🔒
IMEIs como texto: En Excel, formatea la columna IMEI 1 e IMEI 2 como Texto antes de ingresar los números para evitar que Excel los redondee o muestre en notación científica.
