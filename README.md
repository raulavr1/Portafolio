# DevHub — Portafolio Interactivo de Dashboards Empresariales

> **VR · ING. RAUL TECHNOLOGY** — Transformamos datos en decisiones

Portafolio de demostracion interactiva que presenta soluciones de inteligencia de negocios y analitica avanzada. Cada dashboard funciona completamente en el navegador, con datos de muestra cargados automaticamente por sesion.

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/TU_USUARIO/TU_REPO)

## Dashboards incluidos

### VentasPro Suite — Dashboard de Area de Ventas
- Analitica comercial en tiempo real con KPIs interactivos
- Gestion de inventario con alertas de stock minimo
- Facturas y proformas exportables a Excel
- Catalogo digital de productos

### ACTG — Sistema de Prediccion de Incidentes & Geo-Analitica
- Mapas de calor interactivos por zona y cuadrante
- Prediccion de riesgo por turno y tipo de evento
- Carga masiva desde Excel/CSV
- Analisis por franja horaria

---

## Datos de demostracion

Cada sesion de usuario carga automaticamente datos de muestra completos. Los cambios realizados en el dashboard (ediciones, eliminaciones) son **solo visuales y no se guardan** — al cerrar o recargar la pagina los datos vuelven al estado original.

Multiples usuarios pueden usar el dashboard simultaneamente de forma **completamente independiente** sin interferir entre si.

## Despliegue en Vercel

1. Sube este repositorio a GitHub
2. Entra a [vercel.com](https://vercel.com) y conecta tu cuenta de GitHub
3. Importa el repositorio — Vercel detecta automaticamente la configuracion
4. Haz clic en **Deploy**

No se requiere configuracion adicional. El sitio se sirve como sitio estatico directamente desde la raiz del repositorio.
